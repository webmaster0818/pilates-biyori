# ピラティスのロッキングのやり方

**ロッキング（Rocking）**は、うつ伏せで両手を後ろに伸ばして足首を持ち、背中を反らせたまま前後に揺れるエクササイズです。オリジナル34本のひとつで、**[スワンダイブ](/articles/pilates-swan-dive-method/)と並ぶ反り系の上級種目**です。

<CautionNote title="この種目を行う前に">腰椎に既往がある方、椎間板の症状がある方、妊娠中の方は行わないでください。背中を反らせたまま前後に揺れるため、**腰への負担が大きい上級種目**です。膝を深く曲げる姿勢のため、膝に不調がある方も避けてください。</CautionNote>

## 反る位置がすべて

<SwanDiveArcDiagram />

判断の基準は、スワンダイブと同じです。**反りが胸椎（背中の上半分）で起きているか、腰の一点で折れているか。**

ロッキングは足首を持つため、**前ももが硬いほど、体が反りの代わりに腰を折って形を作ろうとします。**

| 状態 | 判定 |
| --- | --- |
| 胸から順にゆるやかな弧 | 正しい |
| 腰の一点で角度が変わる | 腰に集中している |

## スワンダイブとの違い

| | スワンダイブ | ロッキング |
| --- | --- | --- |
| 手 | 離す（体の横） | 足首を持つ |
| 必要な柔軟性 | 胸椎の伸展 | 胸椎＋前ももの柔軟性 |
| 揺れの起点 | 胸の開き | 胸の開き＋脚の引き |
| 難易度 | 上級 | 上級 |

## 効果

| 効果 | 内容 |
| --- | --- |
| 胸椎の伸展 | 丸まりやすい背中の上部を反らせる |
| 前ももの伸長 | 膝を深く曲げて伸ばされる |
| 背面の連動 | 背中・お尻・裏ももが同時に働く |
| 体幹の持久力 | 揺れている間ずっと支える |

## やり方【5ステップ】

### ステップ1：うつ伏せで足首を持つ

うつ伏せになり、膝を曲げて**両手でそれぞれの足首**を持ちます。脚は腰幅。

**届かない場合は無理に伸ばさず**、片脚ずつ、またはタオルを使ってください。

### ステップ2：恥骨を押しつける

**恥骨とお腹をマットへ軽く押しつけ**ます。ここが土台です。

### ステップ3：胸と脚を持ち上げる

息を吸いながら、**脚を手で軽く後方へ引き**、その反発で胸を持ち上げます。

**腕で引っ張り上げないこと。**引く力が強いと腰から折れます。

### ステップ4：前後に揺れる

胸を前へ倒すと同時に脚が上がり、シーソーのように前後に入れ替わります。

**反動で振らないでください。**胸を開いた分の反発で自然に起きる揺れです。

### ステップ5：戻す

**3〜5往復**を目安に、同じ高さで揺れます。回数より、**腰に集中していないか**を優先します。

## 簡易版

### 足首が持てない場合

**片脚ずつ**持ちます。または**タオルを足首にかけて**持ちます。

### 揺れられない場合

**揺れずに、反った位置で3呼吸保つ**だけにします。反る位置の練習は同じようにできます。

### 腰に来る場合

この種目は行わず、**[スワン](/articles/pilates-swan-method/)**に戻ってください。同じ胸椎の伸展を、脚を引く負荷なしで練習できます。

## よくある間違いと対処法

### 腕で引っ張り上げる

もっとも多い崩れです。**手は足首を保持するだけ。**引く力で高さを作ると腰に集中します。

### 反動で振る

戻るときに腰から折れます。**1往復ごとに止められる速さ**にします。

### 膝が開く

反動を脚で逃がしています。**膝を腰幅に保ちます。**

### 首が後ろに落ちる

**視線は少し前の床**に置きます。

## 目安の回数

| レベル | 回数 | 意識すること |
| --- | --- | --- |
| 初めて | 揺れずに反った位置で3呼吸 | 恥骨を残す |
| 慣れてきた | 3往復 | 腕で引っ張らない |
| 継続時 | 5往復 | 同じ高さを保つ |

## 順序

1. **[スワン](/articles/pilates-swan-method/)**（反る位置を覚える）
2. **[スワンダイブ](/articles/pilates-swan-dive-method/)**（手を離して揺れる）
3. **ロッキング**（足首を持って揺れる）

## まとめ

ロッキングは、**高く反る種目ではなく、反りを胸椎に置いたまま揺れる種目**です。前ももが硬いほど、体は腰を折って形を作ろうとします。

腰に集中していると感じたら、スワンに戻るのが最短です。段階を守るほうが、結果的に早く反れるようになります。
