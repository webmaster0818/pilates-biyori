# リフォーマーのエレファントとは

**エレファント（Elephant）**は、リフォーマーの上で背中を丸めた前屈の姿勢をつくり、キャリッジを前後に動かす種目です。象が鼻を垂らした形に見えることから、この名前がついています。

<CautionNote title="この記事の前提">マシン種目は、**スプリングの本数・強さ・フットバーの位置を指導者が設定したうえで**行うものです。この記事は「レッスンで何を見られているか」を理解するためのもので、**自己流で再現するためのものではありません。**</CautionNote>

## 保つ形が、ロングストレッチと正反対

同じ支持系ですが、**保つ形が逆**です。

| | ロングストレッチ | エレファント |
| --- | --- | --- |
| 保つ形 | 一直線 | 背中を丸めた前屈 |
| 主に働く場所 | 体幹全体・肩 | 腹部・裏もも |
| 崩れ方 | 腰が落ちる | 腰が反る／背中が平らになる |

**「どちらも支える種目」とまとめると、要点を外します。**エレファントで一直線をつくると、それは別の種目になります。

## なぜ丸めたまま行うのか

背中を平らにすると、動きの主役が**裏ももの伸び**に移ります。そうすると腹部の仕事が抜けます。

丸めた形を保ったまま台を動かすことで、**腹部が働き続ける**状態をつくります。これがこの種目の目的です。

| 背中の形 | 何が起きているか |
| --- | --- |
| 丸めたまま | 腹部が働き続ける（狙いどおり） |
| 平らになる | 裏ももの伸びが主役になり腹部が抜ける |
| 反る | 腰に負担が移る |

## 見られていること

| 局面 | 見られている点 |
| --- | --- |
| 姿勢をつくる | 背中が丸まっているか・恥骨が引き上がっているか |
| 台を動かす | 丸みが変わらないか |
| 戻す | 音を立てずに止められるか |
| 全体 | 肩がすくんでいないか |

**動かす距離は短くて構いません。**丸めた形が保てる範囲が、その日の可動域です。

## よくある崩れ

### 腰が反る

動かす距離が長すぎます。**短くする**だけで収まります。

### 背中が平らになる

伸ばそうという意識が出ています。**丸みを戻して**から動かします。

### かかとが浮く／体重が前に流れる

体重が腕に乗っています。**体重を脚側にも残す**ように指導が入ります。

### 膝を伸ばしきろうとする

裏ももが硬いと、伸ばすほど骨盤が倒れて背中が平らになります。**膝は軽く曲げたままで構いません。**

## 進める前の条件

1. [フットワーク](/articles/pilates-reformer-footwork/)で台の押し引きに慣れる
2. マットで背中を丸める種目（[スパインストレッチ](/articles/pilates-spine-stretch-method/)など）で丸みをつくれる
3. エレファント（丸めた形のまま台を動かす）

## まとめ

エレファントは、**脚を伸ばす種目ではなく、背中を丸めた形を保ったまま台を動かす種目**です。うまくいかないときに変えるのは回数ではなく、**動かす距離**だけです。

腰が反ったら短くする。それだけで、ほとんどの問題は解決します。
