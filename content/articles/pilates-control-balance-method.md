# ピラティスのコントロールバランスのやり方

**コントロールバランス（Control Balance）**は、逆さの姿勢で片脚を頭の向こうへ、もう片脚を天井方向へ伸ばし、交互に入れ替えるエクササイズです。オリジナル34本の**最後から2番目**に置かれ、実質的に最上級の種目です。

<CautionNote title="この種目を行う前に">頸椎に既往がある方、高血圧・眼圧に不安がある方、妊娠中の方は行わないでください。**逆さの姿勢で首に体重が乗りやすい最上級種目**です。[ジャックナイフ](/articles/pilates-jackknife-method/)を首に体重を乗せずに行えないうちは、この種目に進まないでください。</CautionNote>

## 体重を乗せてよいのは肩甲骨まで

<JackknifeWeightDiagram />

判断の基準はジャックナイフと同じ、たったひとつです。**首に体重が乗ったら、その回は終わり。**

コントロールバランスでは、そこに**脚を交互に入れ替える**という条件が加わります。入れ替えのたびに体重が動くため、首へ移りやすくなります。

| 支えている場所 | 判定 |
| --- | --- |
| 肩甲骨から背中の上部 | 正しい |
| 首・後頭部 | その回は中止 |

## ジャックナイフとの違い

| | ジャックナイフ | コントロールバランス |
| --- | --- | --- |
| 脚 | そろえて天井へ | 片脚ずつ交互に入れ替える |
| 体重 | 一定 | 入れ替えのたびに動く |
| 手 | 体の横 | 最終形では足首を持つ |
| 難易度 | 上級 | 最上級 |

## 効果

| 効果 | 内容 |
| --- | --- |
| 体幹の制御 | 逆さのまま重心の移動を抑える |
| 背骨の分節 | 1つずつ動かして入り、戻る |
| 骨盤の安定 | 脚が入れ替わっても傾かない |
| 集中の持続 | 入れ替えのたびに調整し直す |

## やり方【5ステップ】

### ステップ1：ジャックナイフの位置に入る

仰向けから、**背骨を1つずつ**床から離し、脚を頭の向こうへ運びます。

**この時点で首に体重が乗るなら、先へ進みません。**

### ステップ2：片脚を天井へ

右脚を天井方向へ伸ばし、**左脚は頭の向こうに残します。**支えているのは肩甲骨から背中です。

### ステップ3：手を伸ばす（省略可）

最終形では、**天井側の足首を両手で持ちます。**届かない場合は**手を体の横に置いたまま**で構いません。

**足首を持つことは条件ではありません。**

### ステップ4：脚を入れ替える

息を吐きながら、**上下の脚を交互に入れ替えます。**

**体重の位置を変えないこと。**入れ替えのたびに首へ移るなら、その回は終わりです。

### ステップ5：ゆっくり戻る

背骨を上から1つずつマットへ置いて戻ります。**戻る速さは、入るときの倍**かけます。

**左右各3回**を目安にします。

## 簡易版

### 首に体重が乗る場合

**[ジャックナイフ](/articles/pilates-jackknife-method/)までで止めます。**脚の入れ替えは行いません。

### 足首が持てない場合

**手は体の横**のまま行います。難易度は下がりません（むしろ安全です）。

### 背骨が1つずつ動かない場合

**[ロールオーバー](/articles/pilates-roll-over-method/)**に戻ってください。

## よくある間違いと対処法

### 首に体重が移る

もっとも危険な崩れです。**その時点で中止**してください。

### 反動で入れ替える

勢いで振ると重心が首側へ動きます。**1回ごとに止められる速さ**にします。

### 足首を持とうとして体が崩れる

手を伸ばすと重心が変わります。**持てないなら持たない**判断が正解です。

### 戻りが速い

背骨と首に衝撃が集中します。**倍の時間**をかけて戻ります。

## 目安の回数

| レベル | 回数 | 意識すること |
| --- | --- | --- |
| 初めて | ジャックナイフまでで3回 | 首に乗せない |
| 慣れてきた | 手は体の横で左右各3回 | 体重を動かさない |
| 継続時 | 足首を持って左右各3回 | 戻りをゆっくり |

## 順序

1. **[ロールオーバー](/articles/pilates-roll-over-method/)**（脚を頭の向こうへ運ぶ）
2. **[ジャックナイフ](/articles/pilates-jackknife-method/)**（そこから脚を天井へ）
3. **コントロールバランス**（脚を交互に入れ替える）

## まとめ

コントロールバランスは、**足首を持つ種目ではなく、逆さのまま体重を首へ移さずに脚を入れ替える種目**です。判断の基準はひとつだけで、**首に体重が乗ったらその回は終わり**です。

足首に手が届かなくても、体重を動かさずに入れ替えられていれば、その回は成立しています。
