# ピラティスのシールのやり方

**シール（Seal）**は、体育座りに近い形で足裏を合わせ、後ろへ転がって戻るエクササイズです。オリジナル34本の終盤に置かれ、**[ローリングライクアボール](/articles/pilates-rolling-like-a-ball-method/)の発展形**にあたります。

アザラシ（seal）が手を叩く動きに似ていることから、**転がる前後に足裏で手拍子を打つ**のが特徴です。

## 転がってよい範囲

<RollingRangeDiagram />

転がる種目に共通する条件はひとつです。**首や後頭部まで体重を届かせないこと。**

| 到達点 | 判定 |
| --- | --- |
| 肩甲骨〜背中の中ほど | 正しい |
| 首・後頭部 | 範囲を越えている |

**深く転がるほど上級ではありません。**転がりすぎると、戻るための反動を首で作ることになります。

## ローリングライクアボールとの違い

| | ローリングライクアボール | シール |
| --- | --- | --- |
| 手の位置 | 足首やすねを持つ | 足首の外側から手を通して持つ |
| 足 | そろえる | 足裏を合わせる |
| 追加動作 | なし | 前後で手拍子 |
| 難易度 | 中級 | 中級（保持が難しい） |

足裏を合わせる分だけ**股関節が開き、バランスが取りにくくなります。**

## 効果

| 効果 | 内容 |
| --- | --- |
| 背骨のマッサージ | 背中を1つずつ床に当てる |
| 腹部の制御 | 丸めた形を最後まで保つ |
| バランス感覚 | 戻ったときに止まる |
| 股関節の柔軟性 | 足裏を合わせて開く |

## やり方【5ステップ】

### ステップ1：座って形をつくる

体育座りから、**足裏を合わせ**、足首の外側から手を通して足首を持ちます。

背中は丸め、**足は床から少し浮かせます。**

### ステップ2：バランスを取る

その位置で止まり、**背中の丸みを保ったままバランス**を取ります。ここが保てないうちは転がりません。

### ステップ3：手拍子を打つ

足裏で**3回**軽く打ちます。慣れるまでは省いて構いません。

### ステップ4：後ろへ転がる

息を吸いながら、**背中の中ほどまで**転がります。丸めた形は変えません。

**首まで行かないこと。**

### ステップ5：戻って止まる

息を吐きながら戻り、**バランスの位置で止まります。**止まったらまた手拍子を3回。

**5〜8回**を目安にします。

## 簡易版

### 戻れない場合

**転がる距離を短く**します。半分でも構いません。丸めた形を変えないことが優先です。

### バランスが取れない場合

**足を床につけたまま**、丸めた形で前後に小さく揺れるだけにします。

### 手が足首に届かない場合

**すねを持つ**か、**ももの裏**を持ってください。形が保てることが優先です。

## よくある間違いと対処法

### 首まで転がる

もっとも危険な崩れです。**距離を短くしてください。**

### 反動で戻ろうとする

丸めた形が崩れ、勢いだけで戻ろうとすると失敗します。**形を変えないこと**が唯一のコツです。

### 背中が伸びる

転がった位置で背中が伸びると戻れません。**丸みを最後まで保ちます。**

### 硬い床で行う

背骨が痛みます。**必ずマットの上**で行ってください。

## 目安の回数

| レベル | 回数 | 意識すること |
| --- | --- | --- |
| 初めて | 足をつけたまま前後に揺れる×5 | 丸みを保つ |
| 慣れてきた | 転がる距離を半分で5回 | 首まで行かない |
| 継続時 | 8回（手拍子あり） | 戻って止まる |

## 順序

1. **[ローリングライクアボール](/articles/pilates-rolling-like-a-ball-method/)**（丸めて転がる）
2. **シール**（足裏を合わせて転がる）
3. **[クラブ](/articles/pilates-crab-method/)**（脚を組んでさらに小さく）

## まとめ

シールは、**深く転がる種目ではなく、丸めた形を変えずに戻ってくる種目**です。うまくいかないときに変えるのは回数ではなく、**転がる距離**だけです。

戻れないなら短くする。それだけで、ほとんどの問題は解決します。
