# ピラティスのスパインストレッチのやり方

**スパインストレッチフォワード（Spine Stretch Forward）**は、床に座った状態から背骨を上から順に丸めて前へ倒していくエクササイズです。オリジナル34本のひとつで、**座って行う代表的な種目**です。

見た目は前屈にそっくりですが、目的はまったく違います。

| | 前屈ストレッチ | スパインストレッチ |
| --- | --- | --- |
| 見ているもの | どこまで手が届くか | 背骨を順に丸められるか |
| 主役 | ハムストリングスの伸び | 背骨の分節と腹部 |
| 良い状態 | 遠くまで届く | **届かなくても、1つずつ動いている** |

**手が届かないことは、この種目では問題になりません。**

## 座り方で結果がほぼ決まる

この種目でつまずく人の大半は、動きではなく**開始姿勢**でつまずいています。

床に座ったときに**骨盤が後ろに倒れて背中が丸まってしまう**場合、そこから「丸める」動きはできません。すでに丸まっているからです。

**対処はとても簡単です。**お尻の下にヨガブロック、畳んだバスタオル、クッションなどを敷いて座面を上げてください。骨盤が立つ高さがあれば、この種目は成立します。**高さを使うことは手抜きではなく、正しい準備**です。

## スパインストレッチの効果

| 効果 | 内容 |
| --- | --- |
| 背骨の分節 | 上から順に丸める動きを座位で練習できる |
| 腹部の引き上げ | 丸めながらお腹を薄く保つ |
| 姿勢のリセット | 骨盤を立てて座る感覚が身につく |
| ハムストリングスの伸長 | 結果として自然に伸びる |

## やり方【5ステップ】

### ステップ1：座り方を整える

両脚を前に伸ばし、肩幅よりやや広めに開きます。**坐骨で床を捉え、骨盤を立てて座ります。**倒れてしまう場合は座面を高くしてください。膝は軽く曲がっていて構いません。

### ステップ2：腕を前へ

両腕を肩の高さで前に伸ばします。肩はすくめず、耳から遠ざけたままです。

### ステップ3：頭から丸めていく

息を吐きながら、**あごを引き、頭 → 首 → 胸 → みぞおち**の順に、上から1つずつ丸めていきます。

**倒れるのではなく、丸まるのが先です。**体を前に倒す意識が強いと、背骨が動かないまま股関節だけが曲がります。

### ステップ4：お腹を引き上げたまま止まる

一番深い位置で、**お腹は前に押し出さず、背中側へ引き上げたまま**保ちます。ここで背骨がCの字を描いていれば正解です。手が床に届くかどうかは関係ありません。

### ステップ5：下から積み上げて戻る

息を吸いながら、**腰 → 背中 → 首 → 頭**の順に、下から順番に積み上げて座位に戻ります。最後に頭が乗る形です。

## 硬くてもできる調整

### 骨盤が倒れる → 座面を上げる

ブロック・タオル・クッションで5〜15cm上げます。**これで大半は解決します。**

### 膝裏が痛い → 膝を曲げる

膝を軽く曲げ、必要なら膝の下にタオルを入れます。骨盤を立てることのほうが優先です。

### 壁を使う

壁に背中を預けて座り、壁から背骨を1つずつ剥がす練習をすると、丸める順序がわかりやすくなります。

## よくある間違いと対処法

### 背骨が丸まらず、股関節だけで倒れる

背中がまっすぐなまま前に倒れているパターンです。**あごを引いて、頭から動かす**ことを最初の合図にしてください。

### お腹が前に出る

丸めるときにお腹が緩むと、腰に負担が集中します。**お腹を背中側へ薄く引き込んだまま**丸めます。

### 肩がすくむ

腕を前に伸ばすと肩が上がりやすくなります。**肩を下げたまま腕だけを前へ**送ります。

### 反動で戻る

勢いで起き上がると、背骨を積み上げる練習になりません。**下から1つずつ**が原則です。

## 目安の回数

| レベル | 回数 | 意識すること |
| --- | --- | --- |
| 初めて | 座面を高くして3回 | 骨盤を立てて座る |
| 慣れてきた | 5回 | 頭から順に丸める |
| 継続時 | 5〜8回 | 戻りを下から積む |

## デスクワーク後の2種目セット

座り姿勢が続いた日は、この順が扱いやすいです。

1. **スパインストレッチ**（丸める・5回）
2. **[スワン](/articles/pilates-swan-method/)**（反対方向に伸ばす・5回）

丸めると反らすを両方向やると、片方向だけより戻りやすくなります。

## まとめ

スパインストレッチは**前屈ではありません。**手が届く距離ではなく、**背骨を上から順に動かせているか**だけを見てください。

うまくいかない場合、原因はほぼ座り方です。**座面を上げて骨盤を立てる**——この1つで多くが解決します。背骨を動かす感覚は[ロールアップ](/articles/pilates-roll-up-method/)と共通なので、あわせて取り組むと定着が早くなります。
